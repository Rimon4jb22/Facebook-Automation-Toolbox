
# Facebook Automation Toolbox

A collection of independent JavaScript utilities for automating repetitive Facebook tasks through the browser's Developer Console.

Each script in this repository is **independent**, **self-contained**, and includes its own documentation at the top of the file. You can use only the script you need without depending on any other file.

---

## ✨ Features

- Independent JavaScript automation utilities
- Browser Console compatible
- No installation required
- Easy to understand and modify
- Each script contains its own documentation and usage instructions
- Continuously expanding collection of automation tools

---

## 🚀 How to Use

1. Open the required Facebook page.
2. Press **F12** (or **Ctrl + Shift + I**) to open Developer Tools.
3. Go to the **Console** tab.
4. Open the desired script from this repository.
5. Read the documentation at the top of the script.
6. Copy and paste the script into the browser console.
7. Press **Enter** to execute.
